# Périmètre de publication

Ce dépôt présente une sélection de résultats et de limites scientifiques des explorations 007–025.

La référence historique complète est conservée séparément. Les chiffres présentés sont issus des simulations décrites dans la synthèse de recherche ; les résultats n'établissent pas l'existence d'une conscience subjective.

Ce dépôt ne contient pas les programmes complets ni les données brutes nécessaires à une reproduction intégrale. L'empreinte SHA-256 de la référence historique est fournie dans le README.
